# Public context policy

This public repository stores only sanitized technical context that is safe for
customers, contributors, and search engines to read.

Do not commit prospect lists, contact details, outbound drafts, customer data,
runway notes, account identifiers, pricing negotiations, application materials,
or private agent-session memory. Keep those artifacts in a private workspace.

The canonical public operating documents are `NORTH_STAR.md`, `OFFER.md`,
`RUNTIME.md`, `EVIDENCE.md`, `company/ORGANIZATION.md`, and `CLAUDE.md`.
