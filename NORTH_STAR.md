# North star: the Anchor report-to-implementation engine

When this is working, Anchor turns public evidence about a real Guam business
into a useful report, matches each verified problem to a deliverable solution
and a current market rate, starts a real operator conversation, and converts
the right problems into paid implementation and recurring care.

## Operating sequence

`AnchorScan -> evidence-backed problems -> deliverable solutions -> current
market rates -> quality-checked report -> authorized outreach -> paid work`

The order matters. Anchor does not choose a service first and reverse-engineer
a problem to sell it.
